# Homebrew tap

This is a home for all my Formula and Casks for homebrew.

    brew tap guilospanck/tap

## Casks

| Cask | Description |
| --- | --- |
| [`pomokaffee`](https://github.com/Guilospanck/pomokaffee) | Menu-bar Pomodoro timer that quiets Slack and Focus and keeps the machine awake |
| [`goom`](https://github.com/Guilospanck/goom) | Menu-bar screen recorder |
| [`ai-usage-bar`](https://github.com/Guilospanck/ai-usage-bar) | Menu-bar app showing Claude/Codex usage |

Install with `brew install --cask guilospanck/tap/<name>`.

## Formulas

| Formula | Description |
